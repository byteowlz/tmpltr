# tmpltr benchmark corpus

Synthetic real-world-document corpus for agentic benchmarks: **6,489 PDFs from
130 distinct document templates** across 13 domains (finance, HR, healthcare,
insurance, legal, government, education, logistics, retail, IT/SaaS, real
estate, travel, engineering), 3,844 English / 2,645 German. Every PDF has exact
structured ground truth.

## Layout

- `manifest.jsonl` — one line per template: id, domain, locale, archetype,
  title, description, field sketch
- `templates/<id>.typ` + `<id>.toml` — Typst template + companion content file
  (register with `tmpltr add template`)
- `data/samples/<id>.json` — one hand-checked sample instance per template
- `data/generated/<id>.jsonl` — ~50 gemma-generated instances per template
  (structurally validated against the sample)
- `data/pdfs/<id>/<id>-NNNN.pdf` — rendered documents; `NNNN` is the 0-based
  line number of the gold record in `data/generated/<id>.jsonl`
- `data/corpus.jsonl` — flat index: pdf path, template, domain, locale, gold
  file + line
- `scripts/` — the full pipeline: `verify.sh` (register + compile gate),
  `json2toml.py`, `gemma_author.py` (LLM template authoring with compile-error
  feedback), `compile_corpus.py`
- `CONVENTIONS.md` — template authoring rules incl. known tmpltr-lib quirks

## Regenerating / extending

1. Add a manifest line, then `python3 bench/scripts/gemma_author.py --ids <id>`
   (needs a vLLM OpenAI endpoint on `localhost:18000`, e.g. via ssh tunnel).
2. Bulk data: `bulkgen.py` (runs next to the vLLM server), then
   `compile_corpus.py` locally. All steps are resumable/idempotent.

## Provenance & licensing notes

All entities (people, companies, authorities, IBANs, case numbers) are
fictional, generated by gemma-4-26B with diversity hints; no real personal
data. Templates are original Typst code. Layouts imitate document *genres*
(invoice, Bußgeldbescheid, boarding pass, …), not any specific company's
branded documents.
